## Featured Project · SecureVault

An **offline-first password manager** for Android. All sensitive data stays encrypted on the device, with no server and no cloud dependency.

![Flutter](https://img.shields.io/badge/Flutter-02569B?style=flat-square&logo=flutter&logoColor=white)
![Dart](https://img.shields.io/badge/Dart-0175C2?style=flat-square&logo=dart&logoColor=white)
![SQLite](https://img.shields.io/badge/SQLite-003B57?style=flat-square&logo=sqlite&logoColor=white)
![AES-256-GCM](https://img.shields.io/badge/AES--256--GCM-0A66C2?style=flat-square)
![Argon2id](https://img.shields.io/badge/Argon2id-2E7D32?style=flat-square)
![Status](https://img.shields.io/badge/Status-In%20Development-orange?style=flat-square)

| | |
|---|---|
| **Cryptography** | Argon2id key derivation · AES-256-GCM authenticated encryption |
| **Authentication** | Master password + Android biometric authentication (`local_auth`) |
| **Storage** | Encrypted local database (`sqflite`) · `flutter_secure_storage` for key material |
| **Architecture** | Layered structure (`core` / `data` / `features`) · Provider state management |
| **Privacy** | Offline-first design · Android backups disabled |
