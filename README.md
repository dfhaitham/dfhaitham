## Featured Project · SecureVault

An **offline-first password manager** for Android. All sensitive data stays encrypted on the device, with no server and no cloud dependency.

| | |
|---|---|
| **Stack** | Flutter · Dart · SQLite (`sqflite`) · Provider |
| **Cryptography** | Argon2id key derivation · AES-256-GCM authenticated encryption |
| **Authentication** | Master password + Android biometric authentication (`local_auth`) |
| **Storage** | Encrypted local database · `flutter_secure_storage` for key material |
| **Architecture** | Layered structure (`core` / `data` / `features`) |
| **Privacy** | Offline-first design, Android backups disabled |

**Status:** 🚧 In active development
